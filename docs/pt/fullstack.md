Sistema full stack de cadastro de clientes desenvolvido com Laravel e MySQL. Implantado em ambiente de rede local utilizando XAMPP, permitindo acesso por múltiplos dispositivos via LAN ou Wi-Fi. Inclui interface frontend e lógica backend para gerenciamento de dados de usuários.

### 🔧 Funcionalidades
- Sistema de autenticação (login e controle de acesso).
- Cadastro e gerenciamento de clientes.
- Cadastro de ativos vinculados aos clientes.
- Visualização de dados de clientes e ativos cadastrados.
- Geração de relatórios (documentos/exportação).
- Arquitetura de banco de dados relacional.

---

Projeto web full stack de e-commerce desenvolvido utilizando HTML, CSS, JavaScript, Node.js e MongoDB.

O sistema permite navegação de produtos e serviços, gerenciamento de carrinho de compras, autenticação de usuários com controle de acesso por perfil (cliente e administrador) e operações completas de CRUD para usuários e produtos.

Clientes podem comprar produtos/serviços, gerenciar o carrinho e atualizar informações pessoais, enquanto administradores gerenciam usuários e estoque por meio de um painel dedicado. O sistema integra persistência no servidor (MongoDB) e armazenamento no cliente (localStorage) para gerenciamento de sessão e carrinho.
