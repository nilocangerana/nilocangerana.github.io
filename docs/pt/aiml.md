Um projeto de deep learning distribuído, desenvolvido com Python e PyTorch, com foco na implementação de treinamento utilizando Distributed Data Parallel (DDP).

O projeto implementa uma rede neural convolucional (CNN) para classificação de imagens utilizando o dataset CIFAR-10, com uma pipeline de treinamento próprio que inclui carregamento dos dados, aceleração por GPU, cálculo da perda, otimização e monitoramento do treinamento.

O principal foco é o treinamento distribuído: o processo de treinamento do modelo é projetado para executar em múltiplos processos e GPUs utilizando o PyTorch DDP, permitindo que cada processo treine com uma parte diferente do dataset enquanto sincroniza os parâmetros do modelo entre os processos.

### 🔧 Funcionalidades
- Treinamento distribuído utilizando PyTorch DDP.
- Modelo CNN personalizado para classificação de imagens.
- Treinamento acelerado por GPU utilizando CUDA.
- Parâmetros de treinamento configuráveis através de argumentos de linha de comando.
- Arquitetura modular de treinamento, com componentes separados para modelo, treinamento e dados.
- Projetado para escalar de uma única GPU para múltiplos processos e múltiplas máquinas.
