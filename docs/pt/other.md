<Collapsible title="Emulador JIT em C++ 🔲">

## 🖥️ Showcase
- [GitHub Repository](https://github.com/nilocangerana/cpp_jit-emulator)

---

Este projeto é um emulador desenvolvido em C++ que utiliza um compilador Just-In-Time (JIT) para executar um conjunto de instruções simplificado. O emulador traduz dinamicamente bytecode em código de máquina nativo x86 em tempo de execução.

O projeto foca em conceitos de baixo nível de sistemas, como gerenciamento de memória, decodificação de instruções e geração de código em tempo de execução, servindo como base para o desenvolvimento de emuladores e compiladores JIT mais avançados.

### 🔧 Funcionalidades
- Arquitetura modular com componentes desacoplados (Emulador, CPU, Memória), permitindo fácil extensão e substituição.
- Suporte a múltiplos registradores de CPU.
- Conjunto de instruções incluindo Load, Add, Jump, Jump Condicional (JZ), NOP e Halt.
- Geração de código em tempo de execução com alocação de memória executável.
- Compilação em blocos básicos com cache para evitar recompilações.
